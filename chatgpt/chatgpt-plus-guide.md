## 先了解五种方案

以下价格为截至 2026-09-03 的美元月费基准；结账页可能显示当地币种、税费或不同可售方案。

| 方案 | 美元月费 | 主要定位 |
| --- | ---: | --- |
| Free | $0 | 基础使用；消息、上传、图像和高级工具通常采用较低的动态限额 |
| Go | 以账户内价格为准 | 面向希望获得高于 Free 使用量、但不需要完整高级权益的用户 |
| Plus | $20/月 | 提供更高使用量，并扩大对高级模型和工具的访问 |
| Pro $100 | $100/月 | 面向高频专业使用，限额和可用能力高于 Plus |
| Pro $200 | $200/月 | 面向最重度的个人专业工作负载，提供更高等级的访问与限额 |

这张表只说明方案层级，不应被理解为固定功能清单。可选模型、语音、文件上传、图像生成、深度研究、代理、Codex 等能力，以及每项能力的次数或速率限制，都可能因系统负载、产品调整和账户状态而变化。不存在“文件上传不设限”之类可长期保证的结论。决定购买前，请在 ChatGPT 的升级或套餐管理页面逐项核对当前权益。

## 如何选择

- 偶尔问答、总结或体验新能力：先使用 Free。
- Free 限额经常不够，但需求仍以日常对话为主：查看账户是否提供 Go，并对照升级页中的实际权益。
- 日常工作、学习、写作或编程需要更高限额和更多高级工具：通常从 Plus 开始评估。
- Plus 的动态限额持续影响工作，且高级能力能直接产生专业价值：再比较 Pro $100 与 Pro $200。

价格更高不代表任何一次任务都必然得到更好结果，也不代表无限使用。建议先明确自己最常触发的是哪一种限制，再依据账户内显示的方案差异升级。

## 订阅前应核对什么

1. 在 <https://chatgpt.com> 登录你准备长期使用的账户。
2. 打开账户内的升级页面，确认该账户当前可购买的方案、当地价格、税费、续订周期及退款条款。
3. 确认 OpenAI 的服务和相应付款方式在你所在地区受到支持，并遵守当地法律与平台条款。
4. 使用本人有权使用、账单信息真实一致且被结账页接受的付款方式。
5. 记录订阅渠道。网页、Apple App Store 或 Google Play 的账单与取消入口可能不同，应回到原渠道管理。

本文不提供绕过地区限制、伪造账单资料或规避平台风控的方法，也不对任何付款方式的成功率作承诺。

## 通过官方页面订阅与管理

界面名称可能调整，通用流程如下：

1. 登录 ChatGPT。
2. 从个人资料或设置进入升级/套餐页面。
3. 阅读当前方案比较，选择账户实际显示的方案。
4. 在官方结账流程中核对币种、金额、税费和续订周期。
5. 提交付款后，在账户的订阅或账单页面确认状态，并保存收据。

需要降级或取消时，也应从原订阅渠道操作。取消通常影响下一续订周期，而不是立即退还当期费用；具体生效时间和退款资格以结账条款、收据及 OpenAI 帮助中心说明为准。

## 付款或订阅异常怎么处理

- 先查看账户内是否仍显示待处理、已生效或已取消，避免重复购买。
- 核对发卡机构是否拒绝交易、余额或额度是否足够、账单资料是否准确。
- 若通过移动应用订阅，检查对应应用商店的订阅记录。
- 不要连续反复提交，也不要把账号、验证码或付款资料交给代充人员。
- 收集账户邮箱、交易时间、金额、收据和错误信息，通过 OpenAI 帮助中心联系支持；不要在公开帖子中粘贴敏感信息。

## 常见问题

### Plus 包含 API 额度吗？

不包含。ChatGPT Plus 是 ChatGPT 产品内的订阅；OpenAI API 在开发者平台独立启用、独立计费。反方向也一样：API 余额不会自动获得 Plus。开发调用请阅读 [OpenAI API 指南](./openai-api-guide.md)。

### Go、Plus 或 Pro 的使用量是固定的吗？

不一定。OpenAI 会调整模型、工具和限额，部分上限还会随时间窗口或系统状态变化。账户内的套餐页和产品界面比第三方教程更接近当前状态。

### 订阅后为什么看不到某项功能？

可能原因包括功能分批上线、平台版本不同、账户或地区不可用，以及动态限额已经触发。先更新应用、重新登录并检查账户内说明；仍有问题时联系官方支持。

### 可以共享账号或找人代付吗？

不建议交出登录凭据、验证码或个人付款信息。这会增加账号接管、隐私泄露、付款争议和违反条款的风险。

### 主要需求是写代码，还能看什么？

可继续阅读 [Cursor 指南](../cursor/cursor-guide.md)。有关 OpenAI Codex，请参阅 [Codex 专题](../codex/README.md)。
